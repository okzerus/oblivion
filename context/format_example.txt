ПРИМЕЧАНИЕ: Этот пример формата для функций используется по большей части для основных функций (main, tick, и т.п.) где много команд, требующие сортировку и деление по категориям.
Этого формата не следует придерживаться функциям, которые не превышают кол-во выполняемых команд (~20 и менее)
Пример формата:

# Из <источник выполнения этой функции>.mcfunction
